# Design A — The Kinetic Monograph (`DEMODESIGN-A`)

**Md. Shah Abrar Zahin · End-to-End Business Backend Architect**

This standalone project implements **Design A: The Kinetic Monograph** from `../TASK.md` using `../README.md` as the strict source of truth for copy and metrics.

## Philosophy
- **Zero 3D Clutter, 100% Editorial Readability:** Crisp alternating Matte Obsidian (`#09090B`) & Warm Alabaster (`#F7F6F2`) stages with generous typography so business owners and engineering leaders can read every proof point effortlessly.
- **`animmasterlib.dev` + GSAP 3.13+ Motion Craft:**
  - **Hero:** Masked split-line reveal + Mouse Proximity Variable Typography (`wght` + lift) + Scroll-Velocity Kinetic Marquee.
  - **Positioning:** Scroll-scrubbed word-by-word highlight reading + Hover-Curtain comparison rows.
  - **Services (8 Bottlenecks):** Sticky Scale-Stacking Cards (`ScrollTrigger`) with Mouse Radial Spotlight borders.
  - **Selected Work:** Kinetic Hover-Preview Project Index (`gsap.quickTo` floating cursor card with live SVG architecture schematic) + smooth accordion case proof.
  - **Numbers:** Odometer slot-rolling counters + shared mouse spotlight Bento grid.
  - **Toolkit:** `GSAP Flip` layout-morphing filter grid + `ScrambleText` production inspector.
  - **How I Work:** Pinned split-screen scroll-spy (`01 Discover` → `06 Prove`).
  - **Direction:** Clean Typographic Failover Switchboard (`Simulate Outage` → instant SVG failover & zero-downtime proof).
  - **Contact:** Character-wave giant email with 1-click copy + 5 First-Call Questions accordion.

## Quick Start
```bash
cd DEMODESIGN-A
npm install
npm run dev
```
